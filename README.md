# E-Tech: Enterprise E-commerce API

## Technical Profile
- **Architecture:** Senior-level Three-Tier Modular Monolith.
- **Engine:** FastAPI + PostgreSQL (AsyncPG).
- **Security:** JWT Authentication, Argon2 ID Hashing, RBAC.

## Setup
```bash
docker-compose up etech-api
```
Access Swagger: [http://localhost:8000/docs](http://localhost:8000/docs)
